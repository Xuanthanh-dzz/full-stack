# Spaced Review 01 — Chi phí và ownership

Sau cụm (1, 5); ôn lại sau 2 ngày và 1 tuần. Lượt đầu không mở bài.

## Retrieval

1. Big-O phụ thuộc kích thước nào?
2. Amortized khác average thế nào?
3. Array copy có clone object phần tử không?
4. Linked list bỏ tail cuối cần sửa gì?
5. Ôn Module 06: read-only API khác snapshot?

## Dự đoán output

1. List capacity 4, Count 4 rồi Add: phần nào phải copy?
2. Queue enqueue A,B;dequeue;enqueue C: thứ tự còn lại?

## Debug

Dùng RemoveAt(0) cho 100.000 jobs; đếm shifts trước khi sửa. Ghi input, state trước/sau, nguyên nhân và regression test.

## Judgment liên module

Catalog 30 mục đọc một lần: scan hay hash index? Nêu nơi code chạy, state, cost và giải pháp đơn giản nhất phù hợp scale.

## Self-score

Retrieval 10 điểm, trace 4, debug 3, judgment 3. Đạt 16/20 và không bỏ sót precondition thuật toán. Ghi bài cần ôn và thử ví dụ khác sau 2 ngày.
