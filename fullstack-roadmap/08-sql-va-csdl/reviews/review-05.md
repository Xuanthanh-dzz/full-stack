# Spaced Review 05 — Bằng chứng và vận hành

Sau cụm 21–25; quay lại sau 2 ngày và 1 tuần. Không mở bài ở lượt đầu.

## Retrieval

1. Actual plan có chạy query không?
2. SARGable có bảo đảm seek không?
3. Parameter thay tên column được không?
4. VERIFYONLY có thay restore drill không?
5. Ôn file writer Module 06: rollback DB có hủy side effect ngoài không?

## Dự đoán output

1. Hai tên mẫu tách theo dấu cách đầu: dữ liệu nào cần giữ để sửa policy?
2. Checkout quantity 2,giá 1200000: order value và paid revenue có phải cùng số?

## Debug

User reader SELECT được nhưng DELETE cũng được: kiểm grants/role membership bằng identity nào? Nộp input, actual/expected, root cause và test hồi quy.

## Judgment liên module

100 orders/ngày: chọn quy trình backup/restore và tối ưu dựa evidence, không thêm hệ phân tán. Nêu contract, state ở client/server, chi phí và điều kiện phải đổi quyết định.

## Self-score

Retrieval 10 điểm, trace 4, debug 3, judgment 3. Đạt 16/20 và không bỏ sót sai grain/transaction contract. Ghi bài cần ôn rồi kiểm lại bằng ví dụ khác sau 2 ngày.
